# WhatsApp Sticker Studio

A standalone Android app that makes and organizes WhatsApp stickers better than WhatsApp's built-in tools — high-quality 512×512 sticker creation (image / GIF / video / Giphy), auto-tagged searchable local library, and one-tap export/share into WhatsApp via the official sticker API and share sheet.

## Core loop
Make a better sticker → auto-tagged & saved → find it instantly by meaning → one-tap send/share.
